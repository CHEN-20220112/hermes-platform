配置流（管理员，低频）

管理员          平台后台              Hermes Profile
 ① 创建/编辑专家（提示词/Skill/MCP/模型）
   └────────→ ② 生成渲染配置
              ③ 写 SOUL.md / skills / config.yaml
              └──────────────────→ ④ 加载配置
              ◀──────────────────  ⑤ 生效确认
   ◀──────── ⑥ 保存成功，专家上线

运行时流（飞书用户，高频）

飞书用户     飞书机器人/平台      Hermes（所选专家）      底层 LLM
 ① 选专家（卡片/指令）
   └─────→ ② 路由到专家 Profile
 ③ 发送任务   │
   └─────→ ④ 组装（会话+已下发能力）
            └──────→ ⑤ API Server 调用
                     ⑥ Agent 循环（Skill/MCP/工具）
                     └────────→ ⑦ 模型推理
                     ◀────────  返回
            ◀────── ⑧ 结果（流式）
   ◀──── ⑨ 渲染回复/文件/卡片
            ⑩ 审计/用量入库
职责边界：平台不跑模型、不跑 Agent 循环；真正的执行由 Hermes 完成。本演示用 HermesExecutor 模拟执行以闭环验证配置链路。
